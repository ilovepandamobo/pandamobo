## 首页动效

状态：已加到预览。

- 首屏轮播写在 `src/content/site.ts` 的 `heroBanners`。三帧分别是品牌、四大服务、AI 产品。
- 自动播放约 6.8 秒，悬停、焦点和切到后台时暂停，页面上有暂停按钮、圆点和左右切换。键盘左右方向键也可切换。
- 服务区改成可展开的横排卡片：悬停、点击或键盘会展开当前一项。窄屏改为纵向，并直接显示要点。
- 滚动进入时标题和卡片会浮现，预览里的数字会从 0 计数。渠道和案例品牌名称做了可暂停的滚动条。
- 系统开启“减少动态效果”时，自动播放和位移动画会停掉，内容保持可见。
- 复测 1440×900、390×844、375×812：没有横向滚动，当前主按钮在首屏内。
